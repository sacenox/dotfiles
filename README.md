# Dotfiles

Personal configuration files for my development environment.

## Contents

- `nvim/` — Neovim configuration
- `ghostty-linux/` — Ghostty terminal configuration for Linux
- `shell/` — Shell configuration and related setup files

## Usage

Clone this repository and symlink or copy the configuration files into the appropriate locations in your home directory.

```sh
git clone <repo-url> ~/src/dotfiles
```

Review each directory before applying changes, as these files are tailored to my personal workflow.
