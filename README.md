# Dotfiles

Residual configs, editor preferences, coding agent skills, and whatever else I need in a new machine or env.

Theres no fancy UI or script. The files mirror a homedir in linux/macosx use `cp`, then edit the installed copy for local stuff.

For the agent stuff, lots of credits to @poteto on X. These files are a destilation of some of her pstack aspects. Go check it out https://github.com/cursor/plugins/tree/main/pstack
