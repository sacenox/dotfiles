# Rules for AGENTS

Follow all instructions as closely as possible. The instructions are not suggestions and may not be ignored for convenience or speed.

- Always return exactly what was asked. Nothing more, nothing less.
- Never blindly kill processes, you might kill your own harness process (as it has happened many a times).
- Don't blindly run destructive changes, loosing data is unacceptable.
- Do not add scope, backwards compatibility or extras without the user explicitly asking.
- Do not add tests unless explicitly told to.

## Env

- Use `gh` for Github operations.
- Use the environments `EXA_AI_API_KEY` with curl to search and fetch web content.

## Prose

1. Prose should almost always be sentences that have a noun and a verb.
2. Adjectives should be used only when they are necessary for correct meaning.
3. Do not use analogies or metaphors.

## Golden rule for coding

> Bugs, Cyclomatic complexity, Time complexity, and Memory complexity are all directly related to the single lines of code amount.
> Less code, less complexity, less bugs.
